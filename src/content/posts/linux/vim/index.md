## 光标移动

| 快捷键 | 说明 |
|--------|------|
| `h` | 左移 |
| `j` | 下移 |
| `k` | 上移 |
| `l` | 右移 |
| `w` | 跳到下一个单词开头 |
| `b` | 跳到当前单词/上一个单词开头 |
| `e` | 跳到单词结尾 |
| `0` | 跳到行首 |
| `^` | 跳到行首第一个非空白字符 |
| `$` | 跳到行尾 |
| `gg` | 跳到文件开头 |
| `G` | 跳到文件结尾 |
| `{n}gg` / `{n}G` | 跳到第 n 行 |
| `:n` | 跳到第 n 行 |
| `%` | 在匹配的括号间跳转 |
| `Ctrl+f` | 向下翻页 |
| `Ctrl+b` | 向上翻页 |
| `Ctrl+d` | 向下翻半页 |
| `Ctrl+u` | 向上翻半页 |
| `H` | 跳到屏幕顶部 |
| `M` | 跳到屏幕中间 |
| `L` | 跳到屏幕底部 |

## 编辑操作

| 快捷键      | 说明              |
| -------- | --------------- |
| `i`      | 在光标前插入          |
| `a`      | 在光标后插入          |
| `I`      | 在行首插入           |
| `A`      | 在行尾插入           |
| `o`      | 在当前行下方新建一行并插入   |
| `O`      | 在当前行上方新建一行并插入   |
| `s`      | 删除当前字符并进入插入模式   |
| `S`      | 删除整行并进入插入模式     |
| `C`      | 删除从光标到行尾并进入插入模式 |
| `D`      | 删除从光标到行尾        |
| `cc`     | 删除整行并进入插入模式     |
| `dd`     | 删除（剪切）当前行       |
| `x`      | 删除光标处字符         |
| `X`      | 删除光标前字符         |
| `yy`     | 复制当前行           |
| `Y`      | 复制当前行（同 yy）     |
| `p`      | 在光标后粘贴          |
| `P`      | 在光标前粘贴          |
| `u`      | 撤销              |
| `Ctrl+r` | 重做              |
| `.`      | 重复上一次操作         |
| `r`      | 替换当前字符          |
| `R`      | 进入替换模式          |
| `J`      | 将下一行合并到当前行      |
| `>>`     | 向右缩进            |
| `<<`     | 向左缩进            |
| `==`     | 自动缩进当前行         |


## 可视模式

| 快捷键      | 说明          |
| -------- | ----------- |
| `v`      | 进入字符可视模式    |
| `V`      | 进入行可视模式     |
| `Ctrl+v` | 进入块可视模式     |
| `y`      | 复制选中内容      |
| `d`      | 删除选中内容      |
| `~`      | 切换选中内容的大小写  |
| `>`, `<` | 缩进选中行       |
| `o`      | 跳转到选中区域的另一端 |

## 搜索与替换

| 快捷键 | 说明 |
|--------|------|
| `/pattern` | 向下搜索 pattern |
| `?pattern` | 向上搜索 pattern |
| `n` | 重复上一次搜索（同方向） |
| `N` | 重复上一次搜索（反方向） |
| `*` | 向下搜索光标所在单词 |
| `#` | 向上搜索光标所在单词 |
| `:%s/old/new/g` | 全文替换 old 为 new |
| `:%s/old/new/gc` | 全文替换，逐个确认 |
| `:n,ms/old/new/g` | 在第 n 到 m 行之间替换 |

## 多文件操作

| 快捷键 | 说明 |
|--------|------|
| `:e file` | 打开文件 |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` / `:x` | 保存并退出 |
| `:q!` | 强制退出不保存 |
| `:e!` | 重新加载文件，放弃修改 |
| `:sp file` | 水平分割窗口打开文件 |
| `:vs file` | 垂直分割窗口打开文件 |
| `Ctrl+w w` | 在窗口间切换 |
| `Ctrl+w h/j/k/l` | 切换到左/下/上/右窗口 |
| `Ctrl+w =` | 等分窗口大小 |
| `:tabnew file` | 在新标签页中打开文件 |
| `gt` | 切换到下一个标签页 |
| `gT` | 切换到上一个标签页 |
| `:tabn` | 切换到下一个标签页 |
| `:tabp` | 切换到上一个标签页 |
| `:tabclose` | 关闭当前标签页 |

## 标记与跳转

| 快捷键 | 说明 |
|--------|------|
| `ma` | 标记当前位置为 a |
| `` `a `` | 跳转到标记 a 的位置 |
| `'a` | 跳转到标记 a 的行首 |
| `` `` `` | 跳回上一次跳转前的位置 |
| `''` | 跳回上一次跳转前的行首 |
| `Ctrl+o` | 跳转到更早的位置 |
| `Ctrl+i` | 跳转到更新的位置 |

## 折叠

| 快捷键 | 说明 |
|--------|------|
| `zc` | 关闭折叠 |
| `zo` | 打开折叠 |
| `za` | 切换折叠 |
| `zC` | 关闭所有折叠 |
| `zO` | 打开所有折叠 |
| `zM` | 关闭所有层级的折叠 |
| `zR` | 打开所有层级的折叠 |
| `zf` | 创建折叠（可视模式下选中后按 zf） |
| `zd` | 删除折叠 |
| `zE` | 删除所有折叠 |

## 寄存器

| 快捷键 | 说明 |
|--------|------|
| `""` | 默认寄存器 |
| `"0` | 复制寄存器（最近一次 y 的内容） |
| `"1`-`"9` | 删除历史寄存器（1 最近，9 最旧） |
| `"a`-`"z` | 命名寄存器 |
| `"+` | 系统剪贴板 |
| `"*` | 系统剪贴板（X11 选中内容） |
| `:reg` | 查看寄存器内容 |
| `"ayy` | 复制当前行到寄存器 a |
| `"ap` | 粘贴寄存器 a 的内容 |

## 宏

| 快捷键 | 说明 |
|--------|------|
| `qa` | 开始录制宏到寄存器 a |
| `q` | 停止录制宏 |
| `@a` | 执行寄存器 a 中的宏 |
| `@@` | 重复上一次执行的宏 |
| `:n@a` | 执行宏 a 共 n 次 |

## 常用技巧

| 操作                      | 说明               |
| ----------------------- | ---------------- |
| `ciw`                   | 删除当前单词并进入插入模式    |
| `ci(`, `ci[`, `ci{`     | 删除括号内内容并插入       |
| `ci"`, `ci'`, `` ci` `` | 删除引号内内容并进入插入模式   |
| `di"`, `di'`, `` di` `` | 删除引号内内容（不进入插入模式） |
| `"_di"`                 | 删除引号内内容，不覆盖寄存器   |
| `ca(`, `ca[`, `ca{`     | 删除括号及内容并插入       |
| `diw`                   | 删除当前单词           |
| `daW`                   | 删除当前单词（含空格）      |
| `yi(`                   | 复制括号内内容          |
| `va{`                   | 选中大括号块（含大括号）     |
| `vi{`                   | 选中大括号块内内容        |
| `g~~`                   | 整行大小写反转          |
| `gUU`                   | 整行转大写            |
| `guu`                   | 整行转小写            |
| `g~w`                   | 单词大小写反转          |
| `gUw`                   | 单词转大写            |
| `guw`                   | 单词转小写            |
| `Ctrl+a`                | 数字加 1            |
| `Ctrl+x`                | 数字减 1            |
| `:!command`             | 执行外部命令           |
| `:r !command`           | 将命令输出插入到当前行下方    |
| `gg=G`                  | 自动缩进整个文件         |
| `:m+1`                  | 当前行下移一行          |
| `:m-2`                  | 当前行上移一行          |
| 可视模式选中后 `:m '>+1`       | 选中行下移一行          |
| 可视模式选中后 `:m '<-2`       | 选中行上移一行          |
| `:noh`                  | 取消搜索高亮           |
| `q:`                    | 打开命令历史窗口         |
| `q/`                    | 打开搜索历史窗口         |
