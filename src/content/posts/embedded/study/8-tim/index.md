# STM32F103C8T6 定时器（TIM）笔记
## 定时器框图

![image.png](https://imgbed.paxseeker.xyz/file/1784884753444_image.png)

### 框图结构详解

#### 基础单元（定时器核心）

| 结构 | 全称 | 作用 | 寄存器 |
|------|------|------|--------|
| **TIM CK** | 定时器时钟输入 | 来自 APB1 或 APB2 总线的原始时钟 | 无（硬件信号） |
| **PSC** | Prescaler 预分频器 | 对输入时钟分频，降低计数频率。分频比 = PSC+1 | `TIMx->PSC` |
| **CNT** | Counter 计数器 | 核心计数器，按分频后的时钟递增/递减计数 | `TIMx->CNT` |
| **ARR** | Auto-Reload Register 自动重装载寄存器 | 计数器计到这个值后溢出，触发更新事件，CNT 归零重新开始 | `TIMx->ARR` |

**工作流程**：

```
36MHz (APB1)
   │
   ▼
[ PSC = 71 ]  →  36MHz / 72 = 0.5MHz → 1 计 = 2us
   │
   ▼
[ CNT ]  0 → 1 → 2 → ... → ARR=1000 → 溢出，回零
                                       │
                                       ▼ 更新事件
                                   触发中断 / DMA
```

> 注意：F103 C8T6 的 APB1 分频为 HCLK_DIV2（=36MHz），当 APB1 分频 ≠ 1 时，定时器时钟自动 ×2 = **72MHz**（不是 36MHz！）

#### 通道（Channel）单元

框图下面部分是 4 个独立的通道，每个通道有一组完整的结构：

```
┌─────────────────────────────────┐
│  通道x (CHx)                     │
│  ┌─────┐    ┌─────┐             │
│  │ CNT │───▶│ CCR │ 比较          │
│  └─────┘    └──┬──┘             │
│               ▼                 │
│         ┌──────────┐            │
│         │ 输出比较  │──► CHx 引脚 │
│         │ /输入捕获 │◄── CHx 引脚 │
│         └──────────┘            │
└─────────────────────────────────┘
```

| 结构       | 全称                       | 作用                                       | 寄存器                |
| -------- | ------------------------ | ---------------------------------------- | ------------------ |
| **CCRx** | Capture/Compare Register | 捕获/比较寄存器。输出比较时与 CNT 比较产生输出；输入捕获时锁存 CNT 值 | `TIMx->CCR1~CCR4`  |
| **OCx**  | Output Compare 输出比较      | 当 CNT 与 CCR 匹配时，控制引脚输出高/低/翻转             | 由 `TIMx->CCMRx` 配置 |
| **ICx**  | Input Capture 输入捕获       | 外部边沿到来时，将 CNT 值锁存到 CCRx                  | 由 `TIMx->CCMRx` 配置 |
| **CHx**  | Channel 引脚               | 通道的物理引脚，复用为定时器通道功能                       | GPIO 复用配置          |

**输出比较工作流程**：

```
CNT:  0 ──── 500 ──── 1000 ── 0 ──── 500 ──── 1000 ──
              │        │        │        │        │
CCR:  500 ◄───┤        │        │        │        │
              │        │        │        │        │
输出:  低 ──── 高 ──── 低 ──── 高 ──── 低 ──── 高 ────  (PWM1 模式)
```

#### 触发器（Trigger）单元

框图右侧是触发系统，分为输入触发和输出触发两部分：

```
外部触发 ──┐
内部定时器 ──┤──► [TRGI 触发输入选择] ──► [从模式控制器] ──► 启动/停止/复位 CNT
ETR 引脚 ────┘
```

| 结构                  | 全称                      | 作用                                               |
| ------------------- | ----------------------- | ------------------------------------------------ |
| **TRGI**            | Trigger Input 触发输入      | 从多个触发源中选择一个作为输入：内部定时器（TIMx_TRGO）、外部引脚（ETR）、内部时钟等 |
| **Slave Mode Ctrl** | 从模式控制器                  | 根据选择的工作模式，在触发沿到来时执行：启动计数、停止计数、复位 CNT、门控计数        |
| **ETR**             | External Trigger 外部触发输入 | 物理引脚（TIM1_ETR, TIM2_ETR 等），可配置滤波器和分频器            |

**触发源选择（TRGx 配置位）**：

| 选择 | 触发源 | 来源 |
|------|--------|------|
| 000 | ITx_IN0 (TI1) | 通道1信号 |
| 001 | ITx_IN1 (TI2) | 通道2信号 |
| 010 | ITx_IN1 (TI3) | 通道3信号 |
| 011 | ITx_IN1 (TI4) | 通道4信号 |
| 100 | ITx_0 | 滤波器0输入 |
| 101 | ITx_1 | 滤波器1输入 |
| 110 | ETRF | 外部触发引脚 |
| 111 | Internal Clock | 内部时钟（默认） |

#### 输出触发（TRGO）

定时器不仅可以接收触发，也可以向外输出触发信号给其他定时器或外设：

```
[TIMx 更新事件] ──► [TRGO 触发输出] ──► 其他外设（TIMy, DAC, ADC）
```

| 输出模式 | 含义 |
|----------|------|
| **Reset** | 每次溢出时 TRGO 产生一个复位脉冲 |
| **Enable** | 定时器启动时 TRGO 输出一个脉冲 |
| **Update** | 每次溢出时 TRGO 输出（最常用） |
| **Compare** | 通道匹配时 TRGO 输出 |

**主从模式（Master/Slave）**：

```
TIM1（主）          TIM3（从）
  │                   │
  │ TRGO 输出 ────────▶ 接收 TRGI
  │ 溢出事件                │
  │                   从模式启动计数
```

#### 其他结构

| 结构                    | 全称                               | 作用                                                                  |
| --------------------- | -------------------------------- | ------------------------------------------------------------------- |
| **SR**                | Status Register 状态寄存器            | 记录各类事件标志位：更新事件（UIF）、触发事件（TIF）、各通道捕获/比较中断标志（CC1IF~CC4IF）、溢出中断（CC1OF） |
| **DMA**               | Direct Memory Access             | 允许将定时器事件自动传输到内存，无需 CPU 参与。可配置触发 DMA 的事件源                            |
| **Deadtime Gen**      | 死区发生器（仅高级定时器）                    | 在互补输出之间插入一段关断时间，防止上下桥臂同时导通                                          |
| **Break Input**       | 刹车输入（仅高级定时器）                     | 紧急停止信号，收到后强制所有通道输出进入安全状态                                            |
| **REP**               | Repetition Counter 重复计数器（仅高级定时器） | 控制更新事件频率：每 REP 次溢出才产生一次更新事件                                         |
| **Complementary Out** | 互补输出（仅高级定时器）                     | 每个通道除 CHx 外还有 CHxN（反相输出），用于 H 桥驱动                                   |

#### 框图整体数据流

```
外设时钟 (APB1/APB2)
       │
       ▼
┌─────────────────────────────────────────────────────────┐
│                    TIMx 定时器                           │
│                                                         │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐             │
│  │  PSC     │──▶│  CNT     │──▶│  ARR     │             │
│  │ 预分频器  │   │  计数器   │   │ 重装载    │             │
│  └──────────┘   └────┬─────┘   └──────────┘             │
│                      │ 共享                             │
│    ┌─────────────────┼─────────────────┐               │
│    ▼                 ▼                  ▼              │

│    │                 │                   │             │
```

## 一、STM32 定时器分类

### 1. 通用定时器（General-Purpose Timer, TIM2~TIM5）

通用定时器具有以下功能：
- 16 位自动重装载计数器（CNT）
- 16 位预分频器（PSC），分频范围 1~65535
- 4 个独立通道（CH1~CH4），每个通道支持：
  - 输入捕获（Input Capture）
  - 输出比较（Output Compare）
  - PWM 输出
  - 单脉冲模式
- 编码器接口（支持 A/B 相及 A/B 相方向检测）
- 支持硬件触发模式

**特点**：适用于常规定时、PWM 输出、输入捕获等场景。

### 2. 高级定时器（Advanced Control Timer, TIM1、TIM8）

高级定时器在通用定时器基础上增加了：

- **互补输出**：每个通道多一个互补输出引脚（CH1N~CH4N），用于三相电机驱动等场景
- **死区时间控制**（Dead-Time）：防止上下桥臂直通
- **刹车功能**（Break Input）：外部紧急停止信号，可强制所有输出进入安全状态
- **重复计数器**（REP）：控制更新事件频率，降低中断频率
- 所有通用定时器的功能（16 位计数器、预分频、4 通道等）

**特点**：适用于电机控制、H 桥驱动等需要互补输出和保护的场合。

### 3. 基本定时器（Basic Timer, TIM6、TIM7）

- 仅 16 位计数器 + 预分频器
- 无 I/O 通道，不支持 PWM/捕获
- 主要用于通用定时或驱动 DAC 触发

> 注：C8T6 上**无** TIM6、TIM7。

## 四、通道（Channel）详解

### 什么是通道？

**通道（Channel）** 是定时器与外部引脚之间的**硬件连接接口**。

可以把定时器想象成一个工厂：
- **计数器（CNT）** 是工厂里的计件员，在内部不停地数数
- **通道（Channel）** 是工厂的**大门**，让计数的结果能与外部世界通信

一个定时器可以有多个通道（如 CH1~CH4），每个通道对应一个（或一组）GPIO 引脚，互不干扰，可以同时工作。

### 通道能做什么？（三种工作模式）

每个通道都可以工作在以下三种模式之一：

#### 1. PWM 输出（输出比较 → 自动翻转电平）

**作用**：在引脚上输出 PWM 波形，控制电机速度、舵机角度、LED 亮度等。

**原理**：内部计数器 CNT 从 0 计数到 ARR（周期），当 CNT < CCR（占空比比较值）时输出高电平，否则输出低电平。

| CCR 值 | 占空比 | 用途 |
|--------|--------|------|
| 0~ARR | 0%~100% | 连续可调 |
| 举例 ARR=100，CCR=30 | 30% | LED 亮度调为 30% |

#### 2. 输入捕获（外部信号 → 计数值被"锁存"）

**作用**：测量外部信号的**脉宽**、**频率**、**周期**。

**原理**：当外部引脚出现上升沿/下降沿时，定时器将当前 CNT 值**锁存**到捕获/比较寄存器（CCR）中。两次捕获的差值就是脉宽或周期。

**典型应用**：
- 测量超声波测距模块的脉宽（HC-SR04）
- 测量电机编码器的转速
- 解码红外遥控信号

#### 3. 输出比较（定时翻转引脚电平）

**作用**：在**精确的时刻**翻转 GPIO 电平，产生单脉冲或精确延时。

**原理**：当 CNT == CCR 时，引脚电平按设定翻转（置高/置低/翻转）。

**典型应用**：
- 产生精确宽度的单脉冲
- 多路独立定时开关

---

### 通道 vs 引脚的关系

```
定时器 TIM3
├── 内部计数器 CNT（独立，所有通道共享同一个时钟源）
├── 通道1 ─── PA6 / PB4   ─── 可以输出PWM1、捕获1、比较1
├── 通道2 ─── PA7 / PB5   ─── 可以输出PWM2、捕获2、比较2
├── 通道3 ─── PB0 / PA2   ─── 可以输出PWM3、捕获3、比较3
└── 通道4 ─── PB1 / PA3   ─── 可以输出PWM4、捕获4、比较4
```

- **一个定时器 = 一个计数器 + 多个通道**
- 所有通道**共享同一个计数器**（同一个时钟源），所以它们产生的 PWM 频率天然同步
- 每个通道有**自己独立的 CCR 值**，可以输出不同占空比的 PWM

### 通道与无通道的区别

| 定时器           | 有无通道    | 能做什么                 |
| ------------- | ------- | -------------------- |
| TIM2~TIM4（通用） | ✅ 4 个通道 | PWM、输入捕获、输出比较、定时中断   |
| TIM6~TIM7（基本） | ❌ 无通道   | 只能定时中断，不能输出波形或捕获外部信号 |

### 影子寄存器（Shadow Register）

#### 为什么需要影子寄存器？

定时器有些关键参数（ARR、CCRx、PSC）是在运行中直接参与工作的。如果修改后立即生效，会在**当前计数周期中途**突然出现跳变，导致输出波形**毛刺**。

**影子寄存器**就是为了解决这个问题：修改值先存入"预装载寄存器"，等计数器下一个更新事件（溢出/重载）时才**一次性切换到"影子寄存器"**生效，保证波形平滑过渡。

```
用户写入 → 预装载寄存器（Preload）
                     ↓ （等待更新事件 UEV）
              影子寄存器（Shadow，实际工作）
                     ↓
                CNT / 通道使用此值
```

#### 哪些寄存器有影子？

| 寄存器 | 预装载功能 | 说明 |
|--------|-----------|------|
| **ARR** | TIMx->ARR 的 ARPE 位使能 | PWM 周期平滑切换 |
| **CCRx** | TIMx->CCMRx 的 OCxPE 位使能 | PWM 占空比平滑切换 |
| **PSC** | TIMx->PSC 的 ARPE 位使能 | 分频比平滑切换 |

#### 开 vs 关预装载对比

**开启预装载**（推荐用于 PWM）：

```
周期0:  ARR=100 ──────► 引脚正常输出
写ARR=200（周期0期间）
     预装载=200，影子仍=100，输出不变
周期0结束（溢出）──► 影子←预装载=200，下周期生效
周期1:  ARR=200 ──────► 引脚用新周期，无毛刺
```

**关闭预装载**（立即生效）：

```
周期0:  ARR=100 ──────► 引脚正常输出
写ARR=200（周期0期间）
     影子立即=200，CNT 可能已 > 200
结果：  当前周期突然变化 → 输出毛刺 / 占空比错乱
```

#### 什么时候关预装载？

- **输入捕获**：需要立即生效，不需要平滑切换 → 关
- **输出比较 / PWM**：需要避免毛刺 → 开

### 从模式（Slave Mode）

#### 什么是从模式？

默认情况下，定时器用**内部时钟**自己驱动计数。但定时器也可以设为**从模式**，让它的启动/停止/复位由**外部事件**或**另一个定时器**来控制。

#### 触发来源

一个定时器可以从以下来源接收触发信号：

```
外部触发信号（ETR引脚）
       │
定时器B 的某个输出事件（如溢出、通道匹配）
       │
外部引脚上的边沿（TIE）
       │
触发器输入选择（TS）──────────► 定时器A 的从模式控制器
                                            │
                                    计数/停止/复位/门控
```

#### 四种从模式

| 模式 | 效果 | 典型应用 |
|------|------|----------|
| **冻结（Frozen）** | 触发到来时停止计数 | 同步多个定时器启动 |
| **触发计数（Triggered）** | 触发到来时启动计数，不自动重载 | 单脉冲发生器 |
| **复位（Reset）** | 触发到来时把 CNT 清零 | 编码器归零 |
| **外部时钟模式1** | 用外部信号的上升沿作为时钟源 | 测量外部信号频率 |

#### 级联定时器的经典用法

```
TIM3（主）            TIM4（从）
  ↑                    ↑
内部时钟 72MHz   接收 TIM3 的溢出触发
ARR=9999  → 1s 溢出 ──► TIM4 启动计数
                        ARR=19999 → 计数2s后中断
```

这样 TIM4 就在 TIM3 溢出后精确启动，实现**定时器级联**或**多定时器同步**。

## 五、时钟来源

- **高级定时器 TIM1**：APB2 总线时钟（72MHz，当 APB2 分频 ≠ 1 时自动 ×2 → 实际 72MHz）
- **通用定时器 TIM2~TIM4**：APB1 总线时钟（36MHz，当 APB1 分频 ≠ 1 时自动 ×2 → 实际 36MHz）
- 系统时钟 HSE = 8MHz，经 PLL ×9 = **72MHz** 系统时钟

---

## 六、实战：TIM3 PWM + TIM4 延时

### 项目概览

| 定时器 | 功能 | 输出引脚 | 时钟配置 |
|--------|------|----------|----------|
| **TIM3** | PWM 输出 → LED 明暗渐变 | PA6 (CH1) | PSC=71, ARR=1000, 1MHz 计数 |
| **TIM4** | 基本定时器 → 微秒延时 | 无 | PSC=71, ARR=65535, 1MHz 计数 |

**时钟计算**（关键）：
```
APB1 分频 = HCLK_DIV2 → APB1 = 36MHz
APB1 分频 ≠ 1 → 定时器时钟自动 ×2 = 72MHz
计数频率 = 72MHz / (PSC+1) = 72MHz / 72 = 1MHz
→ 1 计数 = 1us
```

---

### 1. TIM3 初始化（PWM 输出，PA6 控制 LED 亮度）

```c
// ==== tim.c ====
TIM_HandleTypeDef htim3;

void MX_TIM3_Init(void) {
    TIM_OC_InitTypeDef sConfigOC = {0};

    // 基本定时器配置
    htim3.Instance = TIM3;
    htim3.Init.Prescaler = 71;              /* 72MHz/72=1MHz, 1计=1us */
    htim3.Init.CounterMode = TIM_COUNTERMODE_UP;  /* 向上计数 0→ARR */
    htim3.Init.Period = 1000;               /* PWM 周期: 1MHz/1000 ≈ 1kHz */
    htim3.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
    // 关键：PWM 输出必须开启自动重装载预装载，避免 ARR/CCR 变更时产生毛刺
    htim3.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_ENABLE;
    HAL_TIM_Base_Init(&htim3);

    // PWM 模式初始化
    HAL_TIM_PWM_Init(&htim3);

    // 通道配置：PWM 模式1，初始占空比 50%
    sConfigOC.OCMode = TIM_OCMODE_PWM1;     /* 模式1：CNT<CCR 时输出高电平 */
    sConfigOC.Pulse = 500;                  /* 初始 CCR=500，占空比 500/1000=50% */
    sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;  /* 正极性：默认低，匹配时变高 */
    sConfigOC.OCFastMode = TIM_OCFAST_DISABLE;
    HAL_TIM_PWM_ConfigChannel(&htim3, &sConfigOC, TIM_CHANNEL_1);

    // 启动 PWM 输出（CH1 → PA6）
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
}
```

**GPIO 复用配置**（在 `HAL_TIM_MspPostInit` 中，CubeMX 自动生成）：

```c
void HAL_TIM_MspPostInit(TIM_HandleTypeDef *timHandle) {
    if (timHandle->Instance == TIM3) {
        // PA6 复用为 TIM3_CH1，推挽输出，产生 PWM 波形
        __HAL_RCC_GPIOA_CLK_ENABLE();
        GPIO_InitStruct.Pin = GPIO_PIN_6;
        GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;     /* 复用推挽输出 */
        GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
        HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
    }
}
```

**工作原理**：

CCR 改变 → 占空比改变 → LED 亮度改变。预装载使能 → 变化在下一个周期开始时生效，无毛刺。

### 2. TIM4 初始化（基本定时器 → 延时函数）

```c
// ==== tim.c ====
TIM_HandleTypeDef htim4;

void MX_TIM4_Init(void) {
    // 基本定时器配置
    htim4.Instance = TIM4;
    htim4.Init.Prescaler = 71;              /* 同 TIM3: 72MHz/72=1MHz, 1计=1us */
    htim4.Init.CounterMode = TIM_COUNTERMODE_UP;
    htim4.Init.Period = 65535;              /* 16位满量程，约65ms溢出一次 */
    htim4.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
    // 延时函数不输出波形，不需要预装载，关闭即可
    htim4.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_DISABLE;
    HAL_TIM_Base_Init(&htim4);

    // 启动计数器（不需要停，一直计数，delay_us 随时可读）
    HAL_TIM_Base_Start(&htim4);
}
```

**延时函数实现**（`tim.c` ）：

```c
void delay_us(uint16_t us) {
    // 读取当前计数值作为起点
    uint16_t start = htim4.Instance->CNT;

    // 循环等待：CNT - start 累加到 us 为止
    // 利用 16 位减法自动处理溢出（计数器从 65535 回绕到 0 不影响差值）
    while (htim4.Instance->CNT - start < us) {
        // 空转等待
    }
}

void delay_ms(uint32_t ms) {
    // 毫秒延时 = 微秒延时 × 1000
    while (ms--) {
        delay_us(1000);
    }
}
```

### 3. main.c 中调用（PWM 渐变 + 延时同步）

```c
// ==== main.c ====
int main(void) {
    // 初始化外设
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_TIM4_Init();   // 先启动 TIM4 延时
    MX_TIM3_Init();   // 再启动 TIM3 PWM（PA6 LED）

    // 主循环
    uint16_t ccr = 0;           /* 当前占空比（CCR值） */
    int16_t delta = 50;         /* 每次变化步长，正负交替实现呼吸 */

    while (1) {
        delay_ms(100);                      // 用 TIM4 延时 100ms

        ccr += delta;                       // 改变占空比
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, ccr);  // 写入 CCR

        // 到达边界（0% 或 100%），反转方向
        if (ccr >= 1000 || ccr == 0) {
            delta *= -1;
        }
    }
}
```
